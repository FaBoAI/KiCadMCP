# 保存済み銅箔によるネット導通監査

`audit_ground` は、KiCad PCB に保存された銅箔から、指定ネットの導通を幾何学的に調べます。初期値は `GND` です。PCB を変更せず、ゾーンの再充填も実施しません。対象は **2 層基板**です。

```python
from kicad_mcp.ground import audit_ground

result = audit_ground(
    "example.kicad_pcb",
    "checks/ground",             # 新規または空のディレクトリ
    net_name="GND",
    python_executable=None,       # 必要なら pcbnew を import できる Python のパス
    timeout=120,                  # ネイティブ形状抽出の制限時間（秒）
)
print(result["status"], result["passed"])
```

実行側 Python に `pip install '.[geometry]'` で Shapely 2 以降を入れてください。KiCad の `pcbnew` は別プロセスで動かすため、実行側 Python へのコピーや pip インストールは不要です。ネイティブ Python は明示引数、`KICAD_PYTHON`、自動探索の順で決まります。macOS ではネイティブプロセス内で wx を初期化します。

## 判定と出力

| `status` | 意味 |
|---|---|
| `passed` | 監査対象の銅箔が 1 成分で、全端子がそこに接続し、検出した解析上の制限がない |
| `failed` | 独立した銅箔、未接続端子、点・線接触にしか依存できない接続がある |
| `limited` | 未保存のゾーン塗り、対象ネット不在、端子不在、未対応の銅箔要素等があり、合格とは扱えない |
| `unsupported` | 2 層以外など、対象外の構成 |

`passed` が `true` の場合だけ、限定された導通検査に合格したと扱ってください。プロセスが正常終了したことだけでは合格になりません。

出力は `ground_geometry.json`（保存済み形状）、`ground_audit.json`（判定）、`ground_worker.log`（抽出ログ）です。SHA-256 で PCB が処理中に変化していないことを確認します。空でない出力先への上書きは拒否し、`.kicad-mcp-output.lock` を原子的に作成して同じ出力先への並行処理を防ぎます。この予約ファイルは失敗時も残るため、再試行には新しい出力先を使ってください。レポートには部品番号、端子番号、ネット名、座標、入力ファイルパスが含まれます。共有する際は内容を確認してください。

## 接続の扱い

- パッド、配線、ビア、保存済みゾーン塗りを読み取ります。
- 全ドリル穴の空洞を銅箔から除きます。丸穴と長穴を扱います。
- 同じ層の銅箔は、面積が `1e-9 mm²` を超える重なりがある場合だけ接続します。点または線だけで接する形状を橋渡しに使いません。他の面積重なり経路があれば、その経路による接続は認めます。
- 異なる層は、同じめっき穴の壁へ実際に達する銅箔を通して接続します。カスタム PTH パッドの離れた島を、パッド ID が同じという理由だけで接続しません。
- 接続のない銅箔島は、端子を含まなくても不合格とします。端子が一つもないネットは判定を限定します。
- 円弧形状は内接側へ最大 `0.0005 mm` の近似を使い、穴は外接側の多角形で除去します。隙間を埋める許容差処理はしません。極端に狭い接触は、近似により未接続と判定される場合があります。

この検査は **DC の接続関係**だけを対象とします。低インピーダンス、電流容量、EMI、温度上昇、銅箔間のクリアランス、製造可能性は証明しません。保存済みゾーン塗りが回路や配線の最新版と一致することも証明できません。KiCad の DRC・未接続検査と併用してください。銅箔上のネットなし図形や未フラッシュのめっき穴など、現在のモデルで扱わない要素を検出すると `limited` になります。

## テスト

```sh
python -m pytest tests/test_ground.py
```

矩形の面積重なり、点・線接触、代替経路、孤立島、穴による切断、めっき穴の層間接続、カスタム PTH の離れた島を合成形状で検証します。KiCad のネイティブ Python が見つかれば、小さな PCB を一時ディレクトリ内で生成し、保存された銅箔・未充填ゾーン・存在しないネット・4 層拒否・入力不変を検証します。実際の製品基板や試験結果はテストデータに含めていません。
